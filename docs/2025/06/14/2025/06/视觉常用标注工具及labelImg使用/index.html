计算机视觉常用标注工具及labelImg使用

发表于 2025-06-14 分类于 DL ， 标注工具

常用标注工具

工具名称 仓库 主要功能 环境依赖 开发状态 安装方式
LabelImg GitHub 目标检测标注，矩形框，无快捷键 （矩形框标注推荐）。支持yolo、pascal-voc格式。 Python 3.8,3.9 （3.10报错，无法画框） 2024年停止更新但可用 pip/conda
LabelMe GitHub 矩形框（快捷键）、多边形、圆（polygon, rectangle, circle, line, point and image-level flag annotation）。仅json格式输出。 Python 3.x，无特殊说明 2025年仍在更新 pip/conda/APP安装包
Label-Studio GitHub 视频流、音频等，labelImg升级版，需登录 Python 3.6+，Docker 2025年仍在更新，活跃度高 pip/conda/Docker
